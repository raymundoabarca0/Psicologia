Es una guía de metodología de análisis, no una ventaja probada. El script de ejemplo
(si existe) descarga velas públicas de OKX; este entorno no tiene acceso a OKX, así que
para datos se usa paper_signals/market.py (Binance) en su lugar.
Solo se instalaron 8 de las 89 skills del proyecto: las demás dependen de la aplicación
Vibe-Trading (src.quantlib, herramientas propias) o son de mercados chinos.
